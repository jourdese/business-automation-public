# Jourvis

**Business Automation**

Privacy policy, data deletion instructions and support information for Jourvis, operated by **Jour**.

Support: **jourdesepalacio@gmail.com**

The [React frontend](frontend/README.md) is in `frontend/`. Its Vercel project is Jourvis, targeting https://jourvis.vercel.app. To work on it, run `npm ci` and `npm run dev` from that directory. Its interactive examples run locally in the browser and do not create appointments or send messages.

The root-level static policy pages continue to serve https://business-automation-public.vercel.app from the root of `main`, using the Other framework preset with no build command. The Jourvis project builds only `frontend/`, using the checked-in Vercel configuration. These two projects share this repository and have different root directories.

Policy content reflects the current service: requests are handled manually, AI providers may process messages, and no fixed automatic deletion schedule is promised.
