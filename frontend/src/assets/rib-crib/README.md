# The Rib Crib Source Assets

Place the original The Rib Crib image assets in this folder.

Recommended structure:

- `hero/` — hero and banner photos
- `food/` — menu and food photography
- `interior/` — restaurant/interior photos
- `branding/` — logos, marks, signage
- `textures/` — wood/background textures
- `jourvis/` — Rib Crib-specific Jourvis visual assets if needed

These are source assets intended to be imported by React/TypeScript components rather than referenced as root-level public URLs.
